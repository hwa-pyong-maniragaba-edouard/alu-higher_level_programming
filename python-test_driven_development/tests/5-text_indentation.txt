The ``5-text_indentation`` module
=================================

Using ``text_indentation``
--------------------------

Import the function:

>>> text_indentation = __import__('5-text_indentation').text_indentation

Text ending with a delimiter:

>>> text_indentation("Hello.")
Hello.
<BLANKLINE>

Text without a trailing delimiter (no newline at the end):

>>> text_indentation("Hello"); print()
Hello

All three delimiters:

>>> text_indentation("Hello. How are you? Fine: thanks"); print()
Hello.
<BLANKLINE>
How are you?
<BLANKLINE>
Fine:
<BLANKLINE>
thanks

Spaces around lines are removed:

>>> text_indentation("   Hello.    World   "); print()
Hello.
<BLANKLINE>
World

Consecutive delimiters:

>>> text_indentation("What?? Really.")
What?
<BLANKLINE>
?
<BLANKLINE>
Really.
<BLANKLINE>

Empty string:

>>> text_indentation("")
